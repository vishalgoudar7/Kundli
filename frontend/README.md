# Kundli React Frontend
React + Vite frontend for the Node.js Kundli backend.

## Run
1. Copy `.env.example` to `.env`
2. Ensure backend runs on port 5000
3. `npm install`
4. `npm run dev`

API endpoint expected: `POST /api/kundli`.
The UI currently supports D1, D9, planets, Vimshottari Dasha and currentDasha. Optional future `panchanga`, `yogas`, and `doshas` fields render when the backend adds them.
